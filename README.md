**Title:** Zelda Find

**Description of Project:** For this project, we're working on streamlining the learning process of the game franchise The Legend of Zelda. Given its long history with a lot of entries, we hope to be able to offer a way for newcomers to learn about the series and take a dive into what is has to offer without being dumped with too much information or get confused on which lore belongs to which game.

**Description of Target Browser:** Our project will be targeted towards desktop browser users
