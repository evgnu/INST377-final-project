About

Zelda Find is a place to learn all about the long standing gaming series from Nintendo. It is a place to learn about The Legend of Zelda without being bogged down with too much information given its long history of 40 years.

By using the Zelda API, we can present information in a streamlined way dynamically.

For this project, we used a Zelda API created by Deliton Junior and his team, and created a layout that we believed would best be able to help users easily learn about the series. Other than that, we made sure to incorporate the lessons and tools taught to us within the course to finish out the website and make it as user-friendly as we could.
